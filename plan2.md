OVERVIEW:
Saya sedang membuat website ucapan ulang tahun untuk pasangan perempuan. Saya sudah membuat halaman cover, bantu saya mneyelesaikan website ucapan ulang tahun ini.

STACK:

- Vite
- React
- Tailwind CSS

KONSEP & FLOW:

1. Halaman Memories: Buatkan animasi masuk elemen menggunakan CSS vanila, tambahkan dekorasi bunga dengan ukuran kecil di bagian bawah kanan dan kiri (aset sudah saya siapkan di folder assets, beri efek terpaan angin halus seperti pada halaman cover)
2. Halaman Special Message: Buatkan animasi masuk elemen menggunakan CSS vanila, tambahkan dekorasi foto dengan frame yang sudah saya buat komponennya di folder komponen.
3. Halaman Reason You Are Special: Buat halaman baru yang berisi judul utama lalu komponen stack.jsx yang sudah saya buat berisi 5 alasan.
4. Halaman Our Songs: Buat halaman baru yang berisi judul utama lalu daftar 3 lagu menggunakan komponen card songs yang sudah saya buat.
5. Halaman wish: Buat halaman baru yang berisi judul utama lalu wish menggunakan koponen typewriter yang sudah saya buat.

PANDUAN UI & UX:

- Mobile first
- Responsive di berbagai ukuran layar
- Aesthetic, clean, minimalis, cozy
